# Street City Online

Multiplayer open-world Roblox project. Development is in Luau, synchronized with Roblox Studio via Rojo.

> Status: engineering foundation / first drivable prototype. Not published, monetized, or production tested.

See `docs/architecture.md`, `docs/roadmap.md` and `docs/quality.md` after the bootstrap commit. The default branch is `main`; there are no GitHub Actions workflows.
